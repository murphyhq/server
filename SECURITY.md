# Security

Murphy pages people when systems fail, so its own security matters. Thank you for helping keep it safe.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**. Please don't open a public issue, pull request or discussion for a vulnerability.

Include what you found, how to reproduce it, and the version or commit affected. You'll get an answer on the report itself, and you'll be credited in the advisory unless you'd rather not be.

## Supported versions

Fixes are made on `main` and shipped in the next release.
